# Componentes de terceiros

O aviso de direitos reservados de Breno Ludgerio se aplica aos componentes originais do NexusOps. As dependências abaixo mantêm suas próprias licenças. Os identificadores foram conferidos nos metadados dos pacotes instalados; o `package-lock.json` registra as versões resolvidas.

| Componente                  | Licença indicada pelo pacote                        |
| --------------------------- | --------------------------------------------------- |
| React, React DOM            | MIT                                                 |
| Vite                        | MIT                                                 |
| Fastify                     | MIT                                                 |
| Zod                         | MIT                                                 |
| TanStack Query              | MIT                                                 |
| Recharts                    | MIT                                                 |
| React Hook Form e resolvers | MIT                                                 |
| Lucide React                | ISC, com avisos de partes originadas de Feather/MIT |
| TypeScript                  | Apache-2.0                                          |
| Vitest                      | MIT                                                 |
| Playwright                  | Apache-2.0                                          |
| ESLint                      | MIT                                                 |
| DM Sans via Fontsource      | SIL Open Font License 1.1                           |
| Manrope via Fontsource      | SIL Open Font License 1.1                           |

DM Sans e Manrope são incluídas no build por dependências Fontsource, sem consulta ao Google Fonts durante o uso da aplicação. Os avisos integrais das fontes estão preservados em [DM-Sans-LICENSE.txt](third-party/DM-Sans-LICENSE.txt) e [Manrope-LICENSE.txt](third-party/Manrope-LICENSE.txt).

Essa relação apresenta os principais componentes, não substitui a inspeção das licenças de dependências transitivas nem os avisos presentes nos próprios pacotes. Preserve esses avisos ao distribuir componentes de terceiros dentro de uma entrega autorizada.
